# MVP React Project

This is a **Minimal Viable Product (MVP)** web application built with **React** and **TypeScript**, following the **Model-View-Presenter (MVP) architecture**. The project is designed with **responsive layouts for both desktop and mobile** devices.

---

## Features

- **React + TypeScript**: Modern front-end development with type safety.
- **MVP Architecture**: Separation of concerns for better maintainability.
  - **Model**: Handles data and business logic.
  - **View**: Responsible for rendering UI.
  - **Presenter**: Connects Model and View, handles interactions.
- **Responsive Design**: Separate styles for desktop and mobile.
- Easy to extend and scale.
